# Задание для Codex

Ты — senior HTML5 game developer. Продолжи разработку игры Deepforge в этой папке. Сначала прочитай README.md и запусти текущий MVP. Сохрани существующую механику объединения инструментов, покупки, апгрейдов, добычи блоков, кристаллов, бомб, уровня и localStorage. Затем сделай по этапам:

1. Проверь игровой цикл и исправь критические ошибки и softlock-ситуации; добавь гарантированный способ получить базовую кирку, если деньги и инвентарь закончились.
2. Внедри Phaser 3 и Matter.js или эквивалентный движок физики: столкновения инструментов с блоками и между собой, отскоки, корректное разрушение клеток, ограничение количества тел.
3. Добавь полноценную экономику с конфигом баланса, 20 уникальными уровнями, редкими блоками и разными кирками.
4. Добавь собственные визуальные ассеты, эффекты, анимации, звук с mute-переключателем и обучение для новых игроков.
5. Адаптируй интерфейс под мобильные устройства 360–430px, десктоп и сенсорное управление.
6. Подключи Яндекс Игры SDK по актуальной официальной документации: сохранение, пауза, rewarded ads только с согласия пользователя и управление звуком при рекламе. Добавь graceful fallback вне платформы.
7. Добавь тесты основных игровых правил и smoke-тест браузерного запуска. Проверяй изменения после каждого этапа.

Не используй защищённые ассеты, название или изображения Merge Miners. Веди CHANGELOG.md с реализованными изменениями. Покажи команды запуска и сборки.
