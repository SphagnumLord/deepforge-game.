# Яндекс Игры

Локально игра полностью работает без аккаунта, SDK и сетевых запросов к платформе. Платформенный адаптер находится в `src/platform.js`.

## Реализованный контракт

- На домене Яндекса либо при `?platform=yandex` загружается официальный относительный путь `/sdk.js`; если `window.YaGames` уже существует, повторная загрузка не нужна.
- После `YaGames.init()` игра вызывает `getPlayer({ scopes: false })` без показа диалога авторизации. При недоступном игроке сохраняется локальный режим.
- `LoadingAPI.ready()` вызывается после подготовки шахты, отрисовки и обучения. `GameplayAPI.start()`/`stop()` следуют состоянию игры: обучение, карта, скрытая вкладка, ручная пауза, реклама, завершение шахты.
- События `game_api_pause` и `game_api_resume` останавливают/возобновляют симуляцию и звук. Причины паузы учитываются отдельно: закрытие рекламы не снимает ручную паузу или паузу скрытой вкладки.
- `getData(['deepforgeSave'])` загружает прогресс при запуске. Новейший по `updatedAt` корректный снимок выбирается между локальным и облачным сохранением. Старое повреждённое облако не подменяет рабочее локальное сохранение.
- `setData({ deepforgeSave: state }, true)` сохраняет с задержкой 2,5 секунды; записи сериализуются, промежуточные снимки объединяются. Таймауты и ошибки не блокируют игру. Локальная копия пишется сразу после изменения.
- Единственная реклама — `showRewardedVideo` после явного нажатия «Смотреть рекламу · +80 монет». Награда выдаётся только в `onRewarded`, не более одного раза за показ. `onClose` и `onError` снимают рекламную паузу; звук возвращается согласно mute и остальным причинам паузы.

## Проверка на настоящей площадке

1. Выполнить `npm ci` и `npm run build`.
2. Загрузить содержимое `dist/` в черновик игры в консоли разработчика Яндекс Игр. `index.html` должен лежать в корне архива. Не включать `node_modules`, исходники и тесты.
3. Проверить в тестовом запуске консоли: загрузку `/sdk.js`, готовность игры, начальное обучение, паузы и отсутствие звука при сворачивании/рекламе.
4. Проверить облачный прогресс на поддерживаемом аккаунте после закрытия и открытия игры; также проверить недоступное облако и гостевой запуск.
5. Проверить показ rewarded ads по кнопке: успешный просмотр даёт ровно 80 монет, отмена/ошибка — ноль. Реклама не должна запускаться при загрузке, смене шахты или без согласия игрока.
6. Сверить интеграцию с актуальными правилами и документацией перед отправкой на модерацию.

Официальные страницы для сверки:

- https://yandex.ru/dev/games/doc/ru/sdk/sdk-about
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-player
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events

Из этой облачной среды документация возвращала HTTP 403 от сетевого прокси 17 октября 2026. Нужен доступ к `yandex.ru` в настройках сети. Не отключайте TLS-проверки. Доступ к аккаунту разработчика и реальный запуск в консоли в этой задаче не проверены; имитация SDK в тестах не подтверждает поведение настоящей платформы.
