# Deepforge — Шахтёрская империя

Играбельный самостоятельный HTML5-прототип по мотивам жанра merge-mining, без чужих ассетов и без внешних зависимостей.

## Быстрый старт

Откройте `index.html` в браузере. Для локального сервера: `python -m http.server 8000`, затем `http://localhost:8000`.

## Управление

- Нажмите кирку в арсенале, затем нажмите точку над шахтой, чтобы сбросить её.
- Перетащите кирку на такую же для объединения (работает также последовательный выбор двух ячеек).
- Разбивайте блоки, собирайте монеты и кристаллы. Бомбы повреждают соседей.
- Купите кирки и улучшения за монеты.
- Прогресс автоматически сохраняется в `localStorage`.

## Ограничения MVP

Это собственная лёгкая 2D-симуляция с баллистикой и столкновениями с блоками, а не полнофункциональная физика Matter.js. SDK, реклама, звук, сервер и аналитика пока не подключены.
