# Deepforge — Сердце горы

HTML5-игра про шахтёрскую экспедицию: объединение инструментов, добыча, 130 шахт и четыре биома. Canvas 2D отвечает за отрисовку, Matter.js — за физику. Векторная графика и синтезированный звук созданы для проекта; внешние ассеты не используются.

Лицензия Matter.js включена в [THIRD_PARTY_NOTICES.txt](public/THIRD_PARTY_NOTICES.txt) и в готовые сборки.

## Запуск

Чтобы **поиграть без установки**, скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте **`index.html`** двойным щелчком в Chrome, Edge или Firefox. Это готовый самостоятельный файл с кодом, стилями и графикой внутри; сервер и интернет для игры не нужны. Очищать кеш или сохранения не требуется.

Для **разработки**:

Нужен Node.js 22.12+ (в облачной среде проверен Node.js 24).

```bash
npm ci
npm run dev
```

Адрес сервера отображается в терминале. Vite использует шаблон `index.source.html` и модули из `game.js` и `src/`, поэтому изменения исходников доступны сразу.

```bash
npm run build
npm run preview
```

Сборка находится в `dist/`, её можно разместить на статическом хостинге. Сборка также обновляет самостоятельные **`index.html`** в корне и **`dist/deepforge.html`**. После изменений исходников выполните `npm run build` и включите обновлённый корневой `index.html` в коммит. Сам сгенерированный файл редактировать не нужно. Игре не нужны отдельный backend, ключи API или аккаунт для локального запуска.

## Управление

Чтобы поделиться игрой по обычной веб-ссылке, см. [публикацию на GitHub Pages](docs/SHARING.md).

- Выбрать две кирки одного уровня последовательно или перетащить одну на другую, в том числе пальцем.
- Выбрать инструмент и нажать на точку сброса в шахте. На телефоне можно использовать кнопку «Бросить выбранный инструмент»; при фокусе на поле работают Enter и пробел.
- Одновременно работают до пяти инструментов. Каждый имеет ограниченное число ударов и время жизни; брошенная кирка расходуется.
- За монеты покупать новые кирки и улучшать силу будущих бросков; за кристаллы ковать инструменты, уровень которых растёт с поставкой.
- При пустом инвентаре, отсутствии активных инструментов и нехватке монет становится доступна бесплатная кирка. Экспедицию всегда можно продолжить.
- Кнопки в шапке управляют звуком и обучением. Карта показывает 130 шахт; следующая открывается после зачистки текущей. После 130-й можно начать новый поход с накоплениями и трофеями.
- Каждая восьмая шахта — испытание; каждая пятнадцатая — босс с сохраняемым трофеем и постоянным бонусом. Перед боссами есть золотые передышки. Подробности экономики: [docs/BALANCE.md](docs/BALANCE.md).
- Оригинальная фоновая мелодия включается после первого взаимодействия. Её можно выключить отдельно внизу экрана, сохранив звуки добычи.
- Кнопка паузы останавливает симуляцию. При скрытии вкладки добыча и звук также останавливаются.

## Сохранения

`deepforge-save-v2` в localStorage хранит экономику, инвентарь, настройки, прочность всех блоков, здоровье и фазу босса, трофеи. Сохранение `deepforge-mvp-v1` автоматически переносится при отсутствии новой версии. Перезагрузка не восстанавливает уже разрушенные блоки и не выдаёт повторно бонус за зачистку. Активные броски при перезагрузке завершаются; аварийная кирка исключает потерю возможности играть. Если хранилище браузера недоступно, игра продолжает работать в памяти и показывает предупреждение; прогресс в таком режиме потеряется при закрытии.

Яндекс Игры подключаются только на платформе либо с `?platform=yandex`. Локально нет фоновой загрузки SDK и рекламы. Условия настоящей платформенной проверки и текущие ограничения описаны в [docs/YANDEX.md](docs/YANDEX.md).

## Проверки

```bash
npm test
npm run test:browser
npm run build
npm run test:export
npm run balance
```

Unit-тесты проверяют экономику, аварийную кирку, объединение, миграцию сохранений, генерацию шахт, взрывы, физические столкновения и SDK-адаптер. Playwright проверяет реальный бой с боссом, сохранение трофеев и их бонусов, аудиосигнал мелодии и её независимый mute, игровые действия, touch drag, паузу, перезагрузку, ковку, карту, локальный режим и имитацию платформы на десктопе и экранах 360/390/430 px.

Облачная среда уже содержит Chromium. На другой машине установить браузер:

```bash
npx playwright install chromium
```

Можно выбрать браузер через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Для проверки готовой сборки запустить `npm run preview -- --port 4173 --strictPort` и в другом терминале выполнить `DEEPFORGE_BASE_URL=http://127.0.0.1:4173 npm run test:browser`.

## Структура

- `game.js` — интерфейс и игровой цикл.
- `index.source.html` — редактируемый HTML-шаблон для Vite; корневой `index.html` — готовая игра для запуска из папки.
- `src/core.js` — баланс, экономика, боссы, трофеи и сохранения.
- `src/levels.js` — 130 шахт, испытания, золотые передышки и хранители.
- `src/physics.js` — Matter.js, столкновения и ограничения тел.
- `src/renderer.js`, `src/art.js`, `public/assets/` — графика и эффекты.
- `src/audio.js` — звук; `src/platform.js` — платформенный адаптер.
- `tests/` — проверки; [CHANGELOG.md](CHANGELOG.md) — выполненные изменения.
