# Deepforge — готовая игра

Скачайте `deepforge.html` и откройте его в Chrome, Edge или Firefox. Установка и сервер не нужны.

Для веб-версии в настройках GitHub Pages выберите Deploy from a branch → gh-pages → / (root).
