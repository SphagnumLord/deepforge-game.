# Deepforge — Сердце горы

HTML5-игра про шахтёрскую экспедицию: объединение инструментов, проходы к тайникам, 130 шахт и четыре биома. Canvas 2D отвечает за отрисовку, Matter.js — за физику. Векторная графика и синтезированный звук созданы для проекта; внешние ассеты не используются.

Лицензия Matter.js включена в [THIRD_PARTY_NOTICES.txt](public/THIRD_PARTY_NOTICES.txt) и в готовые сборки.

## Запуск

Чтобы **поиграть без установки**, скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте **`index.html`** двойным щелчком в Chrome, Edge или Firefox. Это готовый самостоятельный файл с кодом, стилями и графикой внутри; сервер и интернет для игры не нужны. Очищать кеш или сохранения не требуется.

Для **разработки**:

Нужен Node.js 22.12+ (в облачной среде проверен Node.js 24).

```bash
npm ci
npm run dev
```

Адрес сервера отображается в терминале. Vite использует шаблон `index.source.html` и модули из `game.js` и `src/`, поэтому изменения исходников доступны сразу.

```bash
npm run build
npm run preview
```

Сборка находится в `dist/`, её можно разместить на статическом хостинге. Сборка также обновляет самостоятельные **`index.html`** в корне и **`dist/deepforge.html`**. После изменений исходников выполните `npm run build` и включите обновлённый корневой `index.html` в коммит. Сам сгенерированный файл редактировать не нужно. Игре не нужны отдельный backend, ключи API или аккаунт для локального запуска.

## Управление

Чтобы поделиться игрой по обычной веб-ссылке, см. [публикацию на GitHub Pages](docs/SHARING.md).

- Выбрать две кирки одного уровня последовательно или перетащить одну на другую, в том числе пальцем.
- Кнопка «Объединить всё» бесплатно собирает все доступные пары и цепочки слияний за одно нажатие. Кирки 12-го уровня не объединяются; при отсутствии пар, на паузе и после завершения шахты кнопка недоступна.
- При перетаскивании кирка следует за курсором или пальцем, исходная ячейка тускнеет, подходящая подсвечивается. Слияние отмечается перелётом, вспышкой и названием нового инструмента. Escape отменяет перенос.
- Уровни кирок: 3 — золото, 4 — алмаз, 5 — огонь, 6 — изумруд, 7 — фиолетовое пламя, 8 — чёрный блестящий металл. Рисунок одинаков в мастерской и шахте.
- Цель обычной шахты — пройти один отмеченный вертикальный столбец и коснуться киркой тайника внизу. Уничтожать остальную породу необязательно. В испытаниях и у боссов нужно два прохода, начиная с 64-й шахты — три; после тайников у босса остаётся бой с хранителем.
- Выбрать инструмент и нажать на точку сброса в шахте. Кнопки I/II/III выбирают проход для прицела. На телефоне кнопка «Бросить выбранный инструмент» направляет кирку в выбранный проход; при фокусе на поле работают Enter и пробел.
- Подобранный тайник даёт тёплую вспышку, лучи и короткий музыкальный перелив. Его кирка или бомба поступает только при переходе в следующую шахту. Кирка на один уровень выше новой поставки; при заполненной мастерской она сохраняется в запасе до освобождения ячейки. Бомба бросается отдельной кнопкой, расходует один заряд и взрывает область 3×3. Подобрать тайник бомбой нельзя.
- Одновременно работают до пяти инструментов. Каждый имеет ограниченное число ударов и время жизни; брошенная кирка расходуется.
- За монеты покупать кирки и объединять одинаковые. Плотные слои и броня боссов требуют кирку указанного уровня: высокая сила слабый металл не заменяет.
- Кнопка «Улучшить силу (+1)» показывает прибавку к базовой силе. Подсказка кнопки дополнительно показывает точное изменение урона выбранной кирки с учётом её уровня и трофеев.
- Редкие алмазы залегают в одном-двух глубоких усиленных блоках. За них улучшать силу или ковать инструмент выше уровня поставки; обычный кварц алмазов не даёт.
- На обычной шахте доступна одна аварийная кирка на попытку. На испытаниях и у боссов помощи нет. Когда нет инструментов, активных бросков и средств ни на покупку, ни на ковку, шахта перезапускается автоматически.
- При перезапуске возвращаются запасы на входе, сбрасываются порода и здоровье босса; находки и покупки проигранной попытки откатываются. Новая шахта имеет конечный минимальный бюджет на снабжение. Перезагрузка страницы его не пополняет и не возвращает право на помощь.
- Кнопка «↻ Начать заново» находится над полем. После подтверждения она перезапускает текущую попытку по тем же правилам, убирает летящие инструменты и сохраняет пройденные шахты, рекорд, трофеи и настройки. Завершённую шахту повторно перезапускать нельзя.
- Кнопки в шапке управляют звуком и обучением. Карта показывает 130 шахт; следующая открывается после сбора тайников и победы над хранителем, если он есть. После 130-й можно начать новый поход с накоплениями и трофеями.
- Каждая восьмая шахта — испытание; каждая пятнадцатая — босс с сохраняемым трофеем и постоянным бонусом. Перед боссами есть золотые передышки. Подробности экономики: [docs/BALANCE.md](docs/BALANCE.md).
- Оригинальная фоновая мелодия включается после первого взаимодействия: четыре темы по 16 тактов при 84 BPM, около трёх минут до повторения. Чередуются колокольчики, щипковый тембр, спокойная флейта и челеста; меняются гармония, бас, ответы и ритм. Её можно выключить отдельно внизу экрана, сохранив звуки добычи.
- Кнопка паузы останавливает симуляцию. При скрытии вкладки добыча и звук также останавливаются.
- Над шахтой — вечернее поле и костёр с движущимся пламенем, искрами и клубящимся туманом. У трофеев туман плавно рассеивается, без прямоугольных вырезов. Пауза и reduced motion останавливают анимацию. На породах видны ветвящиеся медные, серебристые, золотые, аметистовые и зелёные декоративные прожилки; редкие добываемые алмазы по-прежнему помечены отдельным значком.
- У поломки кирки есть сухой треск с металлическим призвуком, у взрыва бомбы — низкий удар и затухающий грохот. Цепочка бомб даёт один звуковой взрыв на столкновение; выключение музыки сохраняет оба эффекта.

На широком экране шахта занимает больше места, мастерская стала компактнее. Значок Deepforge повторяет алмазную кирку 4-го уровня. Дневник оформлен раскрытой книгой с бумажными страницами, корешком, закладкой и рисунком компаса.

## Сохранения

`deepforge-save-v2` в localStorage хранит экономику, инвентарь, настройки, прочность блоков, здоровье и фазу босса, трофеи, стартовые запасы попытки, использованную помощь, собранные тайники, заряды бомб и запас призовых кирок. Версия данных — 5; прогресс из v2/v3/v4 и `deepforge-mvp-v1` переносится автоматически. Уже завершённые шахты не требуют повторного сбора тайников и не выдают призы задним числом. Перезагрузка не восстанавливает добытые блоки, не дублирует награды и не снимает лимит помощи. Активные броски после перезагрузки теряются; если запасы исчерпаны, применяются правила аварийной кирки или перезапуска. Если хранилище браузера недоступно, игра продолжает работать в памяти и показывает предупреждение; прогресс в таком режиме потеряется при закрытии.

Яндекс Игры подключаются только на платформе либо с `?platform=yandex`. Локально нет фоновой загрузки SDK и рекламы. Условия настоящей платформенной проверки и текущие ограничения описаны в [docs/YANDEX.md](docs/YANDEX.md).

## Проверки

```bash
npm test
npm run test:browser
npm run build
npm run test:export
npm run balance
```

Unit-тесты проверяют проходы вместо полной зачистки, физический подбор, перенос призов без дубликатов, запас при полном инвентаре, бомбы, конечную помощь, откат проигранной попытки без фарма наград, требования к киркам, редкие алмазы, миграцию, баланс 130 шахт, физику и SDK-адаптер. Playwright проверяет реальный спуск к тайнику, свечение, несколько проходов, получение и расход бомбы, перезапуски и лимит помощи после перезагрузки, реальные столкновения слабых и усиленных кирок, алмазную оплату силы, движение дымки и reduced motion, тихий звук поломки, бой с боссом, трофеи, музыку, touch drag и остальное управление на десктопе и экранах 360/390/430 px.

Облачная среда уже содержит Chromium. На другой машине установить браузер:

```bash
npx playwright install chromium
```

Можно выбрать браузер через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Для проверки готовой сборки запустить `npm run preview -- --port 4173 --strictPort` и в другом терминале выполнить `DEEPFORGE_BASE_URL=http://127.0.0.1:4173 npm run test:browser`.

## Структура

- `game.js` — интерфейс и игровой цикл.
- `index.source.html` — редактируемый HTML-шаблон для Vite; корневой `index.html` — готовая игра для запуска из папки.
- `src/core.js` — баланс, экономика, боссы, трофеи и сохранения.
- `src/levels.js` — 130 шахт, испытания, золотые передышки и хранители.
- `src/physics.js` — Matter.js, столкновения и ограничения тел.
- `src/renderer.js`, `src/art.js`, `public/assets/` — графика и эффекты.
- `src/geology.js` — кешированные текстуры шести пород и процедурный туман.
- `src/camp.js` — вечернее поле, анимированный костёр и плавная маска тумана у трофеев.
- `src/audio.js` — звук; `src/platform.js` — платформенный адаптер.
- `tests/` — проверки; [CHANGELOG.md](CHANGELOG.md) — выполненные изменения.
